# Deutsches Reimlexikon 

Ein kostenloses Reimlexikon für Liedtexter, Autorinnen, Autoren und alle, die auf Deutsch schreiben. 

Das Reimlexikon wurde für die praktische Arbeit entwickelt: schnell, übersichtlich und ohne Werbung. ## Merkmale - über 50.000 Reimwörter - mehrere tausend Reimgruppen - schnelle Suche nach Reimen oder Wörtern - übersichtliche Darstellung in drei Spalten - Trennung von Klein- und Großschreibung - Kopieren eines Reimwortes mit einem Mausklick - funktioniert direkt im Browser – keine Installation erforderlich 

## Online benutzen 
Das Reimlexikon kann direkt hier geöffnet werden: **https://faltschwagoni.github.io/reimlexikon/** 

## Bedienung 
1. Suchbegriff eingeben. 
2. Passende Reimgruppe auswählen. 
3. Reimwort anklicken. 
4. Das Wort wird automatisch in die Zwischenablage kopiert. 

## Mitwirken Verbesserungsvorschläge und Hinweise auf fehlende oder fehlerhafte Reime sind willkommen. ## Entwicklung Das Reimlexikon wird kontinuierlich erweitert und verbessert.
